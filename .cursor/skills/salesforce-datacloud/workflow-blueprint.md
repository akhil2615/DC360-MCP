# Blueprint Workflow

Use this workflow to generate architecture-ready Data360 documentation.

## Steps

1. Identify metadata root (default: `salesforce-app/force-app/main/default`).
2. Run `generate_blueprint` with a brand name.
3. Share the generated standalone HTML from `artifacts/blueprints`.

## Output

- JSON artifact for machine-readable analysis.
- HTML artifact for stakeholder-friendly review.
