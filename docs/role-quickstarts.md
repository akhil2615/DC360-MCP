# Role Quickstarts

## Analyst

1. Use `list_tables` and `describe_table` to inventory queryable entities.
2. Run `query` for diagnostics and KPI checks.
3. Use `generate_blueprint` for a shareable architecture snapshot.

## Architect

1. Use `list_org_inventory` for a full object-level inventory.
2. Export DMO relationships with `export_dmo_relationships`.
3. Generate and review blueprint artifacts via `generate_blueprint`.

## Release Manager

1. Run `run_org_diff` for drift or promotion gap checks.
2. Run `pipeline_retrieve` from source org.
3. Validate promotion path using `pipeline_promote` dry run.
4. Execute `pipeline_deploy_check` in target org before go-live.
